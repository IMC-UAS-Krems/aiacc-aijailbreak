# Robin Hoodie icon assets

The transparent icon is adapted from the supplied hooded archer and laptop image. The project has no application scaffold yet, so these files are ready to connect when the frontend is built.

| File | Suggested use |
| --- | --- |
| `robin-hoodie-logo-source.png` | Full-size transparent master |
| `robin-hoodie-icon-1024.png` | Large app or project icon |
| `robin-hoodie-icon-512.png` | App icon and sharing artwork |
| `robin-hoodie-icon-192.png` | Web app icon and README preview |
| `robin-hoodie-icon-48.png` | Small interface icon |
| `favicon-32.png` | Browser tab icon |

The master was made with the built-in image generation tool using the supplied image as an edit target. Prompt: “Create a transparent-background project icon from the attached hooded archer at laptop illustration. Keep the electric green outline, black hood, three arrows, tan mouth, and green upward arrow on laptop. Center and simplify for legibility at small sizes. Crisp logo-like style. No text or background.” The square sizes are exports from that master with transparent padding.
