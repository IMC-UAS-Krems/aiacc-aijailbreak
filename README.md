# Robin Hoodie

A university project in which players try to recover a fictional password from an AI model, then submit it to a server-side validator to complete a level. For the IMC Krems University course "AI Architecture and Cloud Computing".

- [First-iteration architecture](docs/architecture.md): game behavior, service design, diagrams, and architecture decisions.
- [Detailed project specification](docs/exp_architecture.md): expanded requirements and assessment evidence.
- [Instructions for coding assistants](AGENTS.md): concise repository guidance and links to the relevant documents.
